# Justificativas para revisão na Chrome Web Store

A extensão leva a grade e o progresso de cursos para a biblioteca pessoal do Lume. O pacote da loja se conecta a lumeacademy.site.

| Permissão | Uso |
| --- | --- |
| activeTab | Ler a grade ou abrir o registro manual da aula após clique no popup. |
| scripting | Executar o leitor acionado pela pessoa e registrar o observador nos domínios autorizados. |
| storage | Lembrar se o selo está recolhido e manter na sessão do navegador a associação temporária entre aba e aula. |
| alarms | Encerrar o registro de uma aba que deixou de emitir batimentos. |
| Acesso ao Lume | Entregar a revisão e consultar ou registrar progresso com a sessão existente do navegador. |
| Domínios opcionais de cursos | Localizar o player nas plataformas ativadas individualmente e ler somente a grade, as marcas da plataforma e as medidas de reprodução. |

As fontes locais da extensão são acessíveis nas origens do registro para desenhar o selo. O pacote inclui o código executável. A política pública descreve o envio das medidas ao Lume e a forma de revogar o acompanhamento.
